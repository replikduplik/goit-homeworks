# GoIT Homeworks

GoIT eğitimi sırasında yaptığım ödevler ve takım projeleri tek repoda.
Her klasör ayrı bir repodan taşındı ve **commit geçmişi korundu**. GitHub'da bir klasörün "History" sayfası o ödevin tüm geçmişini gösterir.

**Canlı demolar:** https://replikduplik.github.io/goit-homeworks/

Site, `main`'e her push'ta GitHub Actions ile yeniden oluşturulur (`scripts/build-site.sh`):
statik ödevler olduğu gibi kopyalanır, Vite/React projeleri kendi alt yollarıyla build edilir.
